# Plana 功能迁移到最新上游 · 2026-11-02

## 分支与来源

按用户选择沿用 `AgIzT/W.O.F_NAI_Launcher`，新建 `migration/plana` 分支；旧 `main` 保持 `fa3bc8ae2649d61ae0a4459890e8b5764a577137`，旧工作区及其中未提交的缩略图测试格式变化保持。

GitHub 创建同网络第二个 fork 的请求返回了现有 fork，没有创建第二份远端仓库。用户随后明确选择沿用 fork 和新分支。

迁移分支直接从最新核实的上游 `49e8ed3100fbfa5896fb8467a8b9f72dae522956` 开始。功能来源为旧分支 `62f920820bdcbdd6dc5bf2b00f7bd88d1f7d7be8`，并保留 `6440d0fa` 对本地放大前角色元数据的增量。没有把旧 main 合并进新基线，也没有替换旧 main 或改写已发布历史。

## 移植结果

- 中英文标签、角色／作品分类、别名与 Wiki 摘要预览，紧凑候选条及展开列表。
- 主提示词、负面、角色、全屏与详情共用的只读标签／自然语言译名；宽译名排版、末尾留白、可见范围和缓存行为保持。
- 自动翻译按输入框等待 800ms，组词中不发请求；标签／句子共享串行批量队列，每批 8 项／2,400 字符，间隔至少 300ms；保留过期片段剔除、路由取消、30／60 秒两次临时错误重试及 429 冷却。
- 补全只保留新 `PromptCompletionWrapper` 入口；统一使用现有补全偏好及设置备份白名单，没有并行保留上游旧弹窗状态。
- 移除 TranslationPill、自动切块、翻译调整会话、翻译块落库及 Agent 创建／修改翻译块协议，不增加旧翻译块迁移层。上游临时块的创建、批量转换、编辑、展开、删除、另存为库块继续保留。

上游最新版的相邻数据目录、加密凭据存储、RAG/checkpoint、共现评分、图库、Agent 工作区和四类资源小窗均作为新基线保留。图片请求、更新器、图库 Ctrl 修复已经存在于上游，不再重复应用。上游元数据解析和错误卡片展示保留，仅补上本地放大前请求图片角色元数据的缺口。

## 必要适配

- `NaiSyntaxController` 将上游光标／选区前景修复与译名字距、字号及 reading revision 缓存结合，保留上游权重配色。
- `UnifiedPromptInput` 在译名包装层外恢复上游撤销 Action；提示词文档历史、输入法提交、搜索替换、失焦撤销沿用上游。受限高度下为译名预留空间并限制最小行数；自动增长卡片按当前实际行高计算最小行数，译名开关不会让空卡片异常增高。
- 上游临时块与旧翻译模型曾耦合。此次保留临时块本身，移除其中的译文存储、嵌套翻译控件和对应协议，Dart 与 Node schema 同步拒绝退役字段。
- 独立资源小窗的详情翻译经主进程调用新的纯文本服务，不再构建旧翻译文档。
- 删除仅验证退役翻译功能的用例，保留普通临时块、成对实例、版本／备份保护和撤销测试；将上游光标实绘从旧翻译块改为新译名开／关，并增加退役协议在备份前被拒绝的断言。
- 上游若干测试写死 `E:/node/node.exe`、手动转换 URL 路径或读取仓库外原型图片。改为选择测试 Node、使用 `fileURLToPath`／真实路径比较，缺失原型图片时使用明确的确定性合成图；没有因此跳过原有业务断言。合成图不能作为用户运行界面或真实图片效果证据。
- 完整回归补齐 ComfyUI／画风探索的显示服务替身；Agent UI 替身的草稿清理也与其不落库约定一致，避免在虚拟时钟销毁阶段启动真实磁盘操作。工作区历史测试改用上游 `agentDirectory` 属性；双列键盘／布局测试使用明确排名数据，保留原有导航和几何断言。
- 块编辑器截图仅排除已移除的第六个“翻译”外观选项，断言剩余五种外观均存在，其余区域继续逐像素检查。提示词卡保持上游比例断言，新增译名开关往返尺寸验证；未更新整张基准图或扩大为整窗排除。

## 验证

验证 SDK：Flutter 3.47.7 / Dart 3.13.5。所有模型与生图测试使用本地合成服务／替身，不请求真实 NovelAI 或模型，不操作用户正式图库、索引、草稿或凭据。

最终静态分析无问题；Node 全套 127 项通过、无跳过。Flutter 完整扫描 918 个测试文件，首轮为 9,771 项通过、38 项跳过、34 项错误结果（包括挂起套件终止后连带未完成项）。修复后集中复测 8 个受影响套件，123 项全部通过。以这 8 个套件的最终结果替换首轮对应结果，有效汇总为 **9,804 项通过、38 项跳过、0 项未解决失败**；没有再进行第二次全量运行。

38 个跳过项来自上游既有环境要求：33 项独立 Python RAG 进程／IPC 测试、4 项 GPU 放大审计、1 项显式启用的在线 AI TAG 读取测试。没有为本次迁移新增跳过。繁体与其他语言资源、业务代码生成、LFS 完整性及 `git diff --check` 也已核验。

完整记录在同目录 `upstream-tracking.json`；本机原始日志与汇总在忽略目录 `build/migration/`，包括 `flutter-resume-final.jsonl`、`affected-complete-final.jsonl`、`node-final-clean.log`、`analyze-delivery-final.log` 和 `verification.json`。本次提示词卡部件实绘使用合成数据，已检查中文尺寸，不作为正式运行窗口截图。

Windows Release 已完成 CMake INSTALL 构建并通过 EXE 数据目录身份校验，包含 `desktop_multi_window_plugin.dll` 和 `data/app.so`。本机中文工作区通过 SUBST 映射为 ASCII 路径；第三方 Cargokit 的符号链接解析在该映射下生成错误路径，因此构建时仅临时修正生成目录中的插件 CMake 引用，成功后已恢复，没有修改 pub cache 或提交本机路径。后续构建优先使用真实 ASCII 检出目录，避免依赖盘符映射。

本次未安装或启动应用。源码版本沿用上游 `2.2.4+75`，并不表示定制版已发布。应用内更新源仍按现有配置指向上游；定制包正式发布前必须选择自己的更新渠道，避免安装上游包后覆盖定制功能。

## 后续跟进

`upstream-tracking.json` 固定上游基线、已检查提交、功能来源与永久排除项。以后先抓取上游、检查游标之后的增量，再在开发分支合入；重点审查编辑器、块模型、Agent 协议、偏好与本地化交点。开发分支验证通过后再决定主线切换，不依赖旧版文件覆盖或只看 Git 冲突数量。

每轮至少验证补全／Wiki、译名／队列、文档撤销／输入法、角色参数和临时块，以及变化所涉及的上游模块；原生插件变化时重新构建 Windows。检查记录与功能采用状态分开保存，避免重复审阅或漏掉部分采用项。
