## 回归方式

先在旧实现中运行针对缺陷的新断言，再实现修复。图片请求四条路径、图库首次 Ctrl 以及更新元数据共 14 条断言失败；便携更新夹具另有 4 个场景失败，反斜线对照及发布失败回退原先通过。

- 图片请求覆盖三种动作 × 流式/非流式共六种组合，检查附件字节和顺序、底图/蒙版、参考类型/强度/保真度、原参数不变；文生图保持 Base64 JSON。
- 图库使用真实时间线控件和合成图库，覆盖网格、瀑布流和火车流；检查 Delete 回调拿到的候选、普通点击累加、Esc 后重选，并保留原 Shift 回归。没有执行实际删除。
- 清单通过本地 HTTP 服务保留 Dio 的实际解码行为，覆盖 JSON/octet-stream、缺失、损坏和非对象；安装版/便携版均核对摘要回退，额外检查无效摘要拒绝。
- 更新服务检查启动脚本在关闭应用之前完成、启动失败不关闭应用、脚本 BOM 和中文/单引号路径；关闭与启动均为替身。
- Windows 进程回归使用真实的短命 Dart 父进程、生产辅助进程启动函数及合成 PowerShell 脚本，验证父进程退出后继续执行，并能移动父进程原工作目录；覆盖 ASCII 与中文/空格/单引号/分号/美元符号路径。
- Portable 夹具实际解包并移动临时目录，检查正斜线/反斜线/混合清单、旧 AOT 不覆盖新 AOT、退役文件不复活、自定义文件和相邻数据保留、已有备份拒绝覆盖、发布失败恢复、恢复失败保留备份。假 EXE 不会启动，故障只注入明确的目录交换位置。
- 更新弹窗用 URL 平台替身检查实际点击行为，优先发布页，缺失发布页时保留资产地址回退，不打开真实浏览器。
